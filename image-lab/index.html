01 / REPRESENT

An image is a sequence

Flatten the 4×4 grid into 16 binary pixels. Add START. Each pixel token gets a learned embedding and a position embedding.

02 / LEARN

Guess, compare, update

Training uses the true earlier pixels to predict the next one. Cross-entropy measures the error; backpropagation and Adam adjust the weights.

03 / CREATE

One pixel becomes context

At generation time, the model sees its own sampled pixels. This is autoregressive generation: the same principle as next-token text generation.

A teaching-scale model: simple patterns, not photos. Training runs locally in a Web Worker; no images leave your browser.
